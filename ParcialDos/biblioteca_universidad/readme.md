Pasos para eliminar la base de datos
1. Haz clic en lo que deseas borrar en el panel izquierdo

2. Haz clic en la pestaña "Operaciones" (barra superior)

3. Baja hasta el final de la página, busca la sección "Eliminar base de datos"

4. Haz clic en "Eliminar la base de datos (DROP)"

5. Aparecerá un cuadro de confirmación → haz clic en OK
